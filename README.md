# **SibGost - Система управления гостиницей**

SibGost - программное обеспечение для автоматизации процессов работы гостиницы. Проект включает в себя два кроссплатформенных приложения: клиентское приложение для бронирования номеров и управления личным кабинетом, а также приложение для сотрудников, предназначенное для администрирования гостиницы и обработки броинрований.

## Основные возможности

**Клиентское приложение (ClientApp)**
Приложение предоставляет гостям гостиницы следующие возможности:

* Регистрация и авторизация - создание учётной записи и вход в систему.
* Просмотр номеров - ознакомление с доступными номерами и их характеристиками.
* Бронирование номеров - оформление бронирования с указанием дат заезда и выезда.
* Управление бронированиями - просмотр собственных бронирований.
* Личный кабинет - просмотр и редактирование персональных данных.
* Управление паролем - изменение пароля учётной записи.
* Уведомления - просмотр уведомлений системы.

**Приложение для сотрудников (StaffApp)**
Приложение предназначено для административного персонала и сотрудников гостиницы.

Основные возможности:
* Авторизация сотрудников - вход с учётом назначенной роли.
* Панель управления - доступ к основным функциям управления гостиницей.
* Управление бронированиями - просмотр, создание и обработка бронирований.
* Управление номерами - добавление и редактирование номеров гостиницы.
* Управление категориями - настройка категорий номеров и базовой стоимости.
* Управление удобствами - создание и редактирование списка доступных удобств.
* Управление ценовой политикой - настройка правил ценообразования.
* Управление пользователями - просмотр и администрирование учётных записей.
* История изменений - хранение информации об изменениях бронирований.

## База данных
В проекте для хранения данных используется система управления базами данных SQLite.
Основные сущности:
| Сущность | Описание |
|---|---|
| User | Пользователи системы |
| AppRole | Роли пользователей |
| Room | Номера гостиницы |
| Category | Категории номеров |
| Amenity | Удобства |
| RoomAmenity | Связь номеров с удобствами |
| Booking | Бронирования |
| BookingHistory | История изменений бронирований |
| Notification | Уведомления |
| PricePolicy | Правила ценообразования |

## Роли пользователей
В системе предусмотрено три основные роли:
* Клиент — бронирование номеров и управление личным кабинетом.
* Администратор — административное управление системой.
* Ресепшионист — работа с бронированиями и обслуживание гостей.

## Поддерживаемые платформы
Оба приложения разработаны на .NET MAUI и предусматривают сборку для следующих платформ:
* Windows
* Android
